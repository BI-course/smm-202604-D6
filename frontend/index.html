Request Flow

  1. Client (Postman / cURL / one of the four frontends below)
    Sends a request to https://yourdomain/api/...
  2. NGINX (reverse proxy)
    Terminates HTTPS, serves static files, forwards /api/... to Gunicorn.
  3. Gunicorn (ASGI server)
    Manages worker processes and translates HTTP into Python ASGI calls.
  4. Flask (this app, api.py)
    Routes the request to the matching @app.route and returns a response.
Response returns: Flask → Gunicorn → NGINX → Client
